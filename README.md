# Версия 1
Описание функций «Мини-RMM» (упрощённая версия, 13 действий)
Это укороченная версия той же утилиты: меньше элементов интерфейса, меньше действий, проще логирование. Ниже — что она умеет и чем отличается от полной версии.
1. Интерфейс
Элемент	Назначение
Поле «Имя компьютера»	Имя/адрес целевого ПК (обязательно для почти всех действий)
Поле «MAC (для WOL)»	MAC-адрес для включения по сети
Поле «Сообщение»	Текст для отправки пользователю (п.10)
Выпадающий список «Действие»	13 операций
Кнопка «Выполнить»	Запуск выбранного действия (AcceptButton, работает по Enter)
Окно вывода	TextBox только для чтения, вертикальный скроллинг
Чего нет по сравнению с полной версией:
поля «Пользователь» (домен\логин);
отдельных кнопок RDP, «Кто залогинен?», «Очистить лог», «Сохранить лог»;
функции Write-UIOutput (лог пишется напрямую через AppendText, без таймстампов и без DoEvents);
заголовка-«шапки» с датой и выбранным действием;
накопления лога — перед каждым запуском окно очищается ($textOutput.Clear()).
2. Логика кнопки «Выполнить»
Читает поля Computer, MAC, Message и индекс действия.
Очищает окно вывода.
Если действие не выбрано — просит выбрать.
Для всех действий, кроме п.3 (WOL), требует имя ПК.
Для всех действий, кроме п.3, делает предварительный ping (Test-Connection -Count 1); при неудаче — «Хост недоступен. Отмена.»
Через switch вызывает соответствующую ветку.

3. Список действий (1–13)
Диагностика и информация
№	Действие	Реализация
2	MAC-адреса активных адаптеров	Get-WmiObject Win32_NetworkAdapterConfiguration -Filter "IPEnabled=True"
5	Аптайм и последняя перезагрузка	Win32_OperatingSystem.LastBootUpTime
6	Залогиненные пользователи	quser на удалённом ПК, ручной разбор строк: Пользователь | Сессия | ID | Состояние. Сессия . помечается как «Консоль». Без CIM-деталей (в отличие от полной версии)
7	Информация о системе	Win32_ComputerSystem/OS/BIOS/Processor/LogicalDisk — модель, вендор, серийник, ОС, RAM, CPU, диск C:
8	Сетевые параметры	Win32_NetworkAdapterConfiguration — IP, маска, шлюз, DNS по каждому активному адаптеру
13	Health-check	Ошибки уровня Error в журналах System/Application за 24 ч (до 10 на журнал) + статус служб WinRM и TermService
Управление питанием и сессиями
№	Действие	Реализация
1	Перезагрузка	Restart-Computer -Force -AsJob
3	Wake-on-LAN	Сборка magic-пакета (0xFF×6 + MAC×16), отправка UDP на 255.255.255.255:9. Имя ПК и ping не нужны — работает только по MAC
4	Разлогин RDP-сессий	quser → строки с rdp-tcp → logoff <ID>
Обслуживание
№	Действие	Реализация
9	Очистка печати	Stop Spooler → удаление \spool\PRINTERS\* → Start Spooler
10	Сообщение пользователю	Invoke-WmiMethod Win32_Process Create "msg.exe * <текст>"
11	Удаление профиля	Список папок C:\Users (без системных) → диалог выбора (ComboBox) → Win32_UserProfile.Delete() + Remove-Item -Recurse. Предупреждает, если пользователь залогинен
12	Очистка ETL-логов	Каталоги Diagnosis\ETLLogs\* и WER\ReportQueue/Archive — удаление с подсчётом освобождённых МБ
